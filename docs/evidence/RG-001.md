## Implemented slice

- Versioned admission and authority protobuf contracts preserve the LLD field/enum numbers, distinct GRANTED and ALLOW semantics, and optional value presence.
- C++20 helpers implement transport commitment classification and request validation against trusted tenant/operation/epoch/digest and registered slot/incarnation inputs. They are not an authenticated service.
- Seven wire fixtures and generated-protobuf contract tests cover parsing/serialization, field descriptors, optional absent/zero values, malformed/oversized input, unknown outcomes, and rejection before a test state port.
- CMake builds generated protobuf/gRPC code and separate contract test executables. GitHub Actions defines a Linux build/test job, captured tool/source versions, and artifact export.
- `build-lock.json` is explicitly a candidate, not a validated reproducible environment.

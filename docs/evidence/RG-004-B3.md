# RG-004-B3 — pinned client guards

**Status:** Scoped component verified; ready for review, unmerged. **Scope:** client certificate/time validation and sealed typed RPC calls only. **Source contracts:** PRD8 / SRD5 / HLD4 / LLD5; [B3 contract](https://github.com/kshiteesh28/DistributedRateGuard/blob/feature/RG-004-client-guards/docs/contracts/pinned-client-v1.md). **PR:** [#12](https://github.com/kshiteesh28/DistributedRateGuard/pull/12). **Implementation head:** `0a1b37b6147adb39c885459253d59c8561c9c5cc`.

## Behavior reviewed

Fresh trusted UTC guards the root, own client leaf and exact expected server leaf on every outbound call. Before-forward validation repeats certificate/time checks against the same immutable proof; it does not validate application ALLOW, deadline or active epoch. Credentials, channel and stubs are private; channel retries, hedging and session caching are disabled. NotSent applies only to the current local attempt; Invoked preserves raw transport/response without claiming remote commitment.

The factory bounds/validates PEM, DER pins, role/URI binding and matching noninteractive private keys. RPC messages/metadata are bounded at 16 KiB, credentials at 64 KiB each, target at 256 ASCII bytes, authority calls at min(caller deadline, now+20 ms). No performance guarantee is inferred.

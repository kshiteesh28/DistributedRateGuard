# RG-005 component verification

Recorded 2026-11-23 UTC. Release A component increment, PR #14 targeting `feature/distributed-rateguard`. Product sources remain PRD 8, SRD 5, HLD 4 and LLD 5.

## Implemented components

- A fixed-partition, thread-safe recorder reserves slots before an owning transition, publishes once, and seals each registered producer. Abandoned reservations, exhaustion and missing seals keep incomplete evidence visible.
- An independent structural validator checks an externally supplied run plan, canonical roster, sequences, byte accounting and checksums.
- Streaming export and offline binary reading use the documented version-1 layout. The reader rejects truncation, trailing bytes and corrupted records.
- A POSIX file publisher writes a managed partial file, syncs it, publishes by a no-overwrite hard link, removes the partial name and syncs the directory. Results expose visible publication and durability separately.
- Fixed aggregate counters omit tenant and attempt identifiers. Overflow saturates and makes the totals inexact.
- Offline reconciliation joins exact attempt IDs to externally supplied deadlines. It reports duplicate stages, timestamp inversions, orphan events, late receipts, decision/response gaps, forwarding violations and committed ALLOW debits whose results were unanswered.
- Seven-day cleanup removes only managed final/partial regular files from a caller-serialized private output directory.

The history plan stays strictly below 1 GiB as required by D6. An exact fit to a smaller test budget is accepted. Encoded size is `97 + 39P + 51S` bytes for P producers and S allocated slots. Memory also includes C++ objects and the final snapshot copy, so the encoded cap does not assert a 1 GiB resident-memory limit.

## Remaining acceptance

RG-005 remains in progress. Actual generator, service and supervisor wiring must bind event owners, stop traffic on evidence loss across processes and run cleanup at the output-directory lifecycle boundary. The semantic quota oracle and real clock/commit provenance gate belong to RG-011A with runtime integration. Fault-injected disk-sync/crash behavior and Linux filesystem crash durability remain unverified. Incomplete snapshot diagnostics remain in memory; the binary publisher currently accepts only complete evidence. A persisted incomplete-run summary and operational export/inspection command remain integration tasks.

Structural completion and stage reconciliation never produce quota safety PASS. Release benchmarks and model checking have not run.

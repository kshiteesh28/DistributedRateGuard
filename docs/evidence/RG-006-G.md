# RG-006 Unix HTTP transport evidence

**Scope:** PR #22 / RG-006-G; PRD 8 / SRD 5, HLD 5, LLD 10 and [transport v1](../contracts/docker-engine-unix-http-v1.md). Full RG-006 remains In progress.

## Implemented boundary

Internal IUnixHttpTransport and its private native implementation provide one bounded GET/empty-body POST over a pinned local Unix socket. Immutable path/device/inode/owner checks, peer credentials, per-call descriptors, four-call admission, absolute monotonic deadlines and typed uncertainty protect the exchange. The pure parser handles the selected bounded Content-Length/chunked/EOF profile.

Clock dependency exceptions become ClockFailure. The final clock/deadline/cancellation gate precedes an allocation-free response move. A failure is known-unsent only before a positive write; no automatic retry or redirect occurs. Valid HTTP statuses remain data for the future controller.

## Limits and next integration

Fake peers verify current-UID credential behavior; actual rootful Docker/API/host placement is a separate qualification. The exact post-EOF scheduling race was reviewed in source without a public test-only hook. This evidence does not establish container stop, process exit, epoch fencing, serving authorization, quota safety, latency/throughput or formal release gates.

[PR #23](https://github.com/kshiteesh28/DistributedRateGuard/pull/23) separately reviews the inspect/stop controller, recorded-process probe and real Docker qualification. Durable recovery/orphan reconciliation, an old-start barrier, authenticated activation, witness and verified successor authorization remain open. Main promotion remains PR #13.

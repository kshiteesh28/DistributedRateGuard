## Delivered input

PeerAuthenticator consumes actual TLS AuthContext properties, requires one `tls` transport/URI/leaf PEM, matches exact DER SHA-256 pin and rechecks root plus selected caller validity using trusted UTC. AuthorizationResolver owns the same registry, rechecks time, validates method/role/mode/request bindings and configured permission pairs, and derives cost from policy. Fixed replica identity is carried into private authorized values; unknown selectors never create quota records.

Opaque peer/authorization values retain a single immutable shared payload. Copies, assignments and rvalue construction retain complete ownership without publishing partially updated proof fields. They authorize an input only; they are not quota ALLOW, GRANTED or forwarding permits. Actual commitment phase remains caller-owned.

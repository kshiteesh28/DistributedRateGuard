# RG-006 Docker inspect/stop and process-evidence verification

**Scope:** PR #23 / RG-006-H; PRD 8 / SRD 5, HLD 5, LLD 11 and [control contract](../contracts/docker-process-control-v1.md). Full RG-006 remains In progress.

## Implemented boundary

The internal IRecoveryProcessController validates exact full container ID and eight immutable labels before inspect/stop interpretation. It owns bounded HTTP transport and a read-only recorded-process probe, borrows a qualified clock, requires an explicit supported Engine API version and retains absolute deadline/cancellation and possibly-sent outcomes. Stop acknowledgments do not prove exit and are never automatically retried.

An observed exit requires the matching terminal Docker state, restart disabled and recorded-process absence. Missing procfs entries alone are insufficient: only pidfd_open ESRCH plus same-boot/observer/clock checks corroborate absence. Pending targets provide runtime-only scope. These observations cannot authorize a successor epoch or exclude a delayed Start.

## Native qualification scope

The driver reuses the matched common-clock/image observation, creates one uniquely labeled synthetic container with restart disabled and constrained capabilities/resources/network/filesystem, and supplies a private bounded fixture to the root native probe. The probe must observe pending/recorded running states, reject a tampered stop before dispatch, confirm the original still runs, receive one stop acknowledgment, prove recorded-process absence with matching runtime exit, distinguish pending-only scope and receive an already-stopped acknowledgment on a later explicit call. Independent terminal inspection and exact owned-container cleanup must also pass.

This is one hosted-runner component qualification. Its observed observer PID namespace is a fixture input, not independent proof that any deployment uses the initial host namespace. It does not establish every-participant fencing, orphan completeness, launch/activation safety, durable successor authorization, quota safety, performance gates or formal model checking.
